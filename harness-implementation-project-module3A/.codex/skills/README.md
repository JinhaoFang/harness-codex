# Skill Catalog

These skills are intentionally small and lifecycle-scoped. They are copied into `.claude/skills/` for Claude Code and can be adapted to other platforms.

| Skill | Purpose |
|---|---|
| harness-clarify | Align user intent before implementation. |
| harness-spec | Draft/check Work Unit Contract. |
| harness-ground | Route context from repository truth. |
| harness-tdd | Behavior-first TDD workflow. |
| harness-evidence | Record fresh evidence receipts. |
| harness-review | Plan/close review without replacing evidence. |
| harness-handoff | Generate recovery artifact. |
| harness-waiver | Explicit skipped evidence/risk acceptance. |
| harness-github | Issue/PR discipline. |
| harness-compound | Trace-driven compounding and pruning. |

Skills may guide workflows and call the controller, but they do not own lifecycle state.
