# Architecture (专题 SoT)

> 目的：存放项目的架构设计与关键决策（专题 SoT），并要求能被 World truth（代码/tests）复核。
>
> 重要：本目录不是新的真相层。若与现实冲突，必须回到代码/tests 与验证证据裁决，并更新本目录使其重新对齐。

## 使用边界

- 允许：模块边界、依赖方向、关键不变量、接口契约、迁移策略、非功能性约束（性能/安全/可靠性）。
- 禁止：复制任务 workflow 正文、把架构文档当作“完成证明”、把局部实现细节当作长期规范。

## 最小结构（建议每份文档都包含）

- Intent: 这份架构文档要解决什么问题
- Invariants: 不变量/红线
- Modules: 模块分层与依赖方向
- Interfaces: 对外/对内接口与契约
- Migration: 迁移与回滚边界
- Verification anchors: 关键代码路径 / tests / checks（可复核）
- Freshness: 何时必须视为过期并复核更新

## 入口建议

- 在本目录新增专题文档时，确保每份文档都指向可复核锚点（代码/tests/evidence）。
- 对于重大决策，优先写成短文档并链接到相关实现与验证证据。
