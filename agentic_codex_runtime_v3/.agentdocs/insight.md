# Insight (cross-task)

> 目的：只沉淀**跨任务可复用**的工程 / 迁移 / 治理经验；不复制单次 workflow 正文；不替代 `architecture/` 的专题架构 SoT。

## 规则（硬约束）

- 这里写的是 **可复用经验**，不是任务复盘。
- 禁止粘贴或镜像 `.agentdocs/tasks/<task-id>/workflow.md` 正文。
- 禁止用这里的内容覆盖：
  - Goal truth（`.agentdocs/tasks/<task-id>/plan.md`）
  - Process truth（`.agentdocs/tasks/<task-id>/workflow.md`）
  - World truth（代码 / tests / 运行时行为）
