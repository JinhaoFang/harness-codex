# 新会话 Align Contract (V3)

> 目标：防止 agent 在“还没真正理解任务”时就开始写计划或动代码。

## 1. 原则

1. 先拿地图，再读代码
2. 先证明理解，再进入计划
3. 进入 BUILD 后，以代码现实为主
4. 没有唯一当前任务时，不允许猜

## 2. 新会话必须回答的 8 个问题

1. 当前项目的顶层指导入口是什么？
2. 当前默认任务是哪一个？
3. 当前任务使用哪种目录模型？
4. 当前状态机状态是什么？
5. 当前 phase 的 task pack 是什么？
6. 当前事实由哪些代码 / 测试 / 配置锚点证明？
7. 本会话进入前，仓库状态是否允许当前动作？
8. 还有哪些问题未达到 95% 理解度？
